# Contributing

Thanks for looking at this project.

## Running it
1. Open `index.html` in a browser, or run `npm run serve` and open http://localhost:3000.
2. Run the tests with `npm install` and then `npm test`.

## Making a change
- Keep changes inside `index.html` unless you are adding a new asset.
- Add or update a check in `tests/` for every behaviour you change.
- Run `npm test` before opening a pull request. CI runs the same command.
- Keep the code comments in place and update them when you change a section.
- Update `CHANGELOG.md` under a new heading.

## Images
Only add images you have the right to use commercially. Record the source and licence in `public/images/attribution.json` for each file. See the licence note in the README.

## Style
Follow `.editorconfig`: UTF-8, LF line endings, two-space indentation.
